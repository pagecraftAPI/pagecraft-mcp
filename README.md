# Pagecraft Tools for AI agents (MCP)

Reliable, fairly priced web data tools that AI agents can call through the [Apify MCP server](https://mcp.apify.com/).
Every tool charges only per result, and agents can pay per request. Runs on Apify; you need an Apify account and API token.

## Connect all tools

Add this as a remote (streamable HTTP) MCP server in Claude, Cursor, VS Code or any MCP client:

```
https://mcp.apify.com?tools=pagecraft/app-reviews-scraper,pagecraft/app-store-reviews-scraper,pagecraft/article-extractor,pagecraft/bluesky-scraper,pagecraft/broken-link-checker,pagecraft/website-intelligence,pagecraft/email-dns-security-audit,pagecraft/google-ads-transparency-scraper,pagecraft/google-news-scraper,pagecraft/google-play-reviews-scraper,pagecraft/ats-jobs-scraper,pagecraft/hacker-news-scraper,pagecraft/keyword-suggestions-scraper,pagecraft/ai-agent-readiness-audit,pagecraft/llms-txt-generator,pagecraft/brand-kit-extractor,pagecraft/ocr-image-to-text,pagecraft/pagespeed-checker,pagecraft/pdf-text-extractor,pagecraft/remote-jobs-scraper,pagecraft/rss-feed-reader,pagecraft/seo-site-audit,pagecraft/shopify-products-scraper,pagecraft/sitemap-url-extractor,pagecraft/tech-stack-detector,pagecraft/telegram-channel-scraper,pagecraft/uk-tenders-finder,pagecraft/wayback-machine-snapshots,pagecraft/website-contact-extractor,pagecraft/website-screenshot-pdf,pagecraft/domain-whois-lookup,pagecraft/workday-jobs-scraper
```

Or load a single tool with `https://mcp.apify.com?tools=pagecraft/<tool>` (links below).
